# 평일 아침 브리핑 워크플로 가이드

평일 08:30 에 팀 채널로 브리핑 카드 한 장을 올리는 Power Automate 흐름을 만드는 절차.
봇 코드 없이 **Outlook + Teams 표준 커넥터만** 쓴다. M365 라이선스 안에서 월 $0.

---

## 0. 최종 상태

```
Recurrence (월~금 08:30 KST)
  → 오늘 요일로 팀 업무 규칙 선택 (DayRules)
  → 내 Outlook 받은편지함에서 전사/팀 alias 수신 메일 조회
  → 직전 브리핑 이후 메일만 남기고 경조사 메일 제외 (월요일은 72시간, 나머지는 24시간)
  → Adaptive Card 로 팀 채널에 게시 (Flow bot)
```

### 카드 내용

```
10월 26일 월요일 브리핑
✅ 팀 업무
• TimeSheet 입력
📅 전사 이슈 리마인드
• [전사공지] 11월 정기 보안점검 안내  ·  security@...
[TimeSheet 열기]
```

메일이 없으면 `특이사항 없음` 을 흐리게 표시한다.

### 요일별 팀 업무

| 요일 | 팀 업무 | 버튼 |
|---|---|---|
| 월 | TimeSheet 입력 | TimeSheet 열기 |
| 화 | TimeSheet 아직 입력하지 않았다면 오늘 입력 | TimeSheet 열기 |
| 수 | 금요일 휴가자는 주간보고 미리 작성 | 없음 |
| 목 | 금요일 휴가자는 주간보고 미리 작성 | 없음 |
| 금 | 주간보고 입력 | 없음 |

문구를 바꾸려면 4단계의 `DayRules` 하나만 고친다.

## 1. 흐름 만들기

Teams 의 Workflows 앱 편집기는 식(expression) 입력이 불편하다. **make.powerautomate.com** 에서 만든다.

1. **만들기 → 예약된 클라우드 흐름**
2. 이름 `평일 아침 브리핑`, 반복 간격 `1 주`, 요일 `월 화 수 목 금` 선택 → 만들기
3. `Recurrence` 트리거를 열어 설정:
   - 표준 시간대: `(UTC+09:00) 서울`
   - 시간: `8`, 분: `30`

4. 상단 **저장**

## 1-1. 액션을 추가하고 값을 넣는 법

2~12단계는 모두 아래 동작의 반복이다. 각 단계의 값 앞에 **[식]** 또는 **[붙여넣기]** 를 표시해 두었다.
(새 디자이너 기준. 메뉴 이름은 UI 언어에 따라 조금 다를 수 있다.)

### ① 액션 추가

1. 캔버스에서 마지막 액션(처음엔 `Recurrence`) 바로 아래의 **+** → **작업 추가**
2. 오른쪽 검색창에 액션 이름을 친다. 예: `작성` (영어 UI 는 `Compose`)
3. **데이터 작업** 아래의 **작성** 을 고른다 → 캔버스에 카드가 생기고 오른쪽에 설정 패널이 열린다

### ② 이름 바꾸기

설정 패널 맨 위의 제목(`작성`)을 클릭 → 이 문서의 이름(예: `Now`)으로 바꾸고 Enter.
**값을 넣기 전에** 바꾼다. 아래 식들이 이 이름으로 서로를 찾고,
다른 식이 이미 참조 중인 액션은 이름을 바꿀 수 없다.

### ③ [식] 넣기

1. 설정 패널의 입력 칸(작성 액션은 **입력 / Inputs**)을 클릭한다
2. 칸 옆에 아이콘 두 개가 뜬다: ⚡ 동적 콘텐츠, **fx** 식. **fx** 를 누른다
3. 열린 식 편집기에 이 문서의 식을 붙여 넣고 **추가(Add)**
4. 입력 칸에 `fx` 토큰이 하나 들어가면 성공

> 식을 입력 칸에 **그냥 타이핑하거나 붙여 넣으면 글자 그대로의 문자열**이 되어 동작하지 않는다. 반드시 fx 로 넣는다.
> 클래식 디자이너라면: 입력 칸 클릭 → 옆에 뜨는 팝업의 **식** 탭 → 붙여 넣기 → **확인**.

### ④ [붙여넣기] 넣기

입력 칸을 클릭하고 이 문서의 내용을 **그대로** 붙여 넣는다. fx 를 쓰지 않는다.
안에 든 `@{...}` 도 그대로 둔다.

### 2단계를 마치면

```
Recurrence
    ↓
Now        ← 작성 액션, 입력 칸에 fx 토큰 하나
```

```
convertFromUtc(utcNow(), 'Korea Standard Time')
```

## 3. 공휴일 건너뛰기 (권장)

`Recurrence` 는 공휴일을 모른다. 휴일 목록을 직접 둔다.

**3-1. `Holidays`** — `Now` 아래에 **작성** 액션 추가 → 이름 `Holidays` → 입력에 **[붙여넣기]**. 회사 휴무일로 채운다.

```json
["2026-12-25", "2027-01-01"]
```

**3-2. 조건** — `Holidays` 아래에 **조건(Condition)** 액션 추가 (검색 `조건`, **제어** 아래).
설정 패널에 `값 선택 | 연산자 | 값 선택` 한 줄이 있다.

- 왼쪽 **값 선택** 칸 → **[식]**:

  ```
  contains(outputs('Holidays'), formatDateTime(outputs('Now'), 'yyyy-MM-dd'))
  ```

- 가운데 연산자 → `is equal to` (같음)
- 오른쪽 **값 선택** 칸 → **[식]** `true`

캔버스에서 조건 카드 아래로 **True / False** 두 갈래가 생긴다.

- **True** 갈래의 **+** → **종료(Terminate)** 액션 추가, 상태 `Succeeded`(성공)
- **False** 갈래는 비워 둔다
- 4단계부터는 두 갈래가 다시 합쳐진 **조건 카드 아래**의 **+** 에 추가한다. 갈래 안에 넣지 않는다

## 4. `DayRules` — 요일별 팀 업무

**작성** 액션 추가 → 이름 `DayRules` → 입력에 **[붙여넣기]**. 키는 `dayOfWeek()` 값이다 (1=월 … 5=금).
`<TimeSheet URL>` 을 실제 주소로 바꾼다.

```json
{
  "1": { "day": "월요일", "task": "TimeSheet 입력",
         "actions": [ { "type": "Action.OpenUrl", "title": "TimeSheet 열기", "url": "<TimeSheet URL>" } ] },
  "2": { "day": "화요일", "task": "TimeSheet 아직 입력하지 않았다면 오늘 입력",
         "actions": [ { "type": "Action.OpenUrl", "title": "TimeSheet 열기", "url": "<TimeSheet URL>" } ] },
  "3": { "day": "수요일", "task": "금요일 휴가자는 주간보고 미리 작성", "actions": [] },
  "4": { "day": "목요일", "task": "금요일 휴가자는 주간보고 미리 작성", "actions": [] },
  "5": { "day": "금요일", "task": "주간보고 입력", "actions": [] }
}
```

- `task` 는 자유롭게 고쳐도 된다. 길면 카드에서 자동 줄바꿈된다.
- **`task` 안에 큰따옴표 `"` 와 역슬래시 `\` 를 쓰지 않는다.** 12단계 카드 JSON 에 글자 그대로 끼워 넣어서 카드가 깨진다. 인용이 필요하면 `'` 나 `「」` 를 쓴다.
- 버튼이 필요 없는 요일은 `"actions": []` 로 둔다. **`actions` 키 자체를 지우면 안 된다** (카드 JSON 이 깨진다).
- 나중에 버튼을 붙이려면 1·2번처럼 `{ "type": "Action.OpenUrl", "title": "버튼 글자", "url": "주소" }` 를 넣는다.

## 5. `Rule` — 오늘의 규칙

**작성** 액션 추가 → 이름 `Rule` → 입력에 **[식]**:

```
outputs('DayRules')?[string(dayOfWeek(outputs('Now')))]
```

## 6. `Title` — 카드 제목

**작성** 액션 추가 → 이름 `Title` → 입력에 **[식]**:

```
concat(formatDateTime(outputs('Now'), 'M월 d일 '), outputs('Rule')?['day'], ' 브리핑')
```

## 7. `Since` — 메일 조회 시작 시각

월요일은 금요일 08:30 부터(72시간), 나머지는 전날 08:30 부터(24시간).
**작성** 액션 추가 → 이름 `Since` → 입력에 **[식]**:

```
addHours(utcNow(), if(equals(dayOfWeek(outputs('Now')), 1), -72, -24))
```

## 8. `GetMail` — alias 수신 메일 조회

### 8-1. 액션 고르기 — 이름이 거의 같은 두 액션에 주의

Office 365 Outlook 에는 한글 이름만 봐서는 구별하기 어려운 액션이 둘 있다.

| 한글 화면 이름 | 영어 이름 | 하는 일 | 이 흐름에 |
|---|---|---|---|
| **메일 받기(V3)** | Get emails (V3) | 폴더에서 메일 **목록**을 가져온다 | ✅ 이것 |
| 메일 가져오기(V2) | Get email (V2) | 메시지 ID 로 메일 **한 통**을 가져온다 | ❌ 아님 |

**잘못 고른 신호:** 패널 맨 위에 `메시지 ID *` (필수) 칸이 있으면 V2(한 통짜리)다.
캔버스의 그 카드 → 패널 오른쪽 위 **⋮** → **삭제** 하고 다시 추가한다.

`메일 받기(V3)` 추가하는 법:

1. `Since` 아래 **+** → **작업 추가** → 검색창에 `메일 받기`
2. 결과에서 **Office 365 Outlook** 아래의 **메일 받기(V3)** 를 고른다.
   검색에 안 나오면 **Office 365 Outlook** 커넥터를 눌러 전체 작업 목록에서 찾는다 (가나다순, `메일 가져오기(V2)` 바로 옆)
3. 처음이면 연결을 만든다 (본인 회사 계정 로그인). 연결 이름은 아무거나 괜찮다
4. **액션 제목**(패널 맨 위의 `메일 받기(V3)` 글자)을 눌러 `GetMail` 로 바꾼다.
   연결 이름이 아니라 이 제목이 9단계 식 `body('GetMail')` 이 찾는 이름이다

### 8-2. 매개 변수 넣기

V3 패널에서 **폴더** 칸은 바로 보인다. 나머지는 **고급 매개 변수** 아래 `0/12 표시 중` 같은 드롭다운을 열어
체크하면 칸이 생긴다. 모두 **직접 타이핑하거나 목록에서 고른다** (식 아님).
한글 이름은 Microsoft 한국어 문서 기준이라 화면과 조금 다를 수 있다. 영어 이름으로 대조한다.

| 화면 이름 (한글 UI) | 영어 UI | 값 |
|---|---|---|
| 폴더 | Folder | 폴더 아이콘 → `Inbox` (받은 편지함) |
| 받는 사람 또는 참조 | To Or CC | `전사alias@회사도메인;팀alias@회사도메인` |
| 읽지 않은 메시지만 가져오기 | Fetch Only Unread Messages | `아니요` |
| 첨부 파일 포함 | Include Attachments | `아니요` |
| Top | Top | `25` |

`받는 사람 또는 참조` 는 받는 사람·참조 중 하나라도 일치하면 가져온다. alias 사이는 세미콜론 `;` 이고 공백을 넣지 않는다.
받은편지함 규칙으로 alias 메일을 다른 폴더로 옮기고 있다면 `폴더` 를 그 폴더로 바꾼다.

## 9. `FilterMail` — 직전 브리핑 이후 메일만, 경조사 제외

액션 추가 검색에 `필터` → **데이터 작업** 의 **배열 필터링(Filter array)** → 이름 `FilterMail`.

- **From** 칸 → **[식]** `body('GetMail')?['value']`
- 조건 줄 아래의 **고급 모드에서 편집(Edit in advanced mode)** 을 누르면 조건이 텍스트 칸 하나로 바뀐다.
  그 칸의 내용을 지우고 아래를 **[붙여넣기]** (맨 앞 `@` 까지 포함)

```
@and(greater(ticks(item()?['receivedDateTime']), ticks(outputs('Since'))), not(or(contains(coalesce(item()?['subject'], ''), '訃告'), contains(coalesce(item()?['subject'], ''), '[부고]'), contains(coalesce(item()?['subject'], ''), '[출산소식]'))))
```

두 가지 조건을 동시에 본다.

1. 받은 시각이 `Since` 이후
2. 제목에 **경조사 말머리가 없음** — 임직원 개인 경조사 메일을 카드에서 뺀다

| 구분 | 제외 말머리 |
|---|---|
| 부고 | `訃告` (괄호 없이 어디든) `[부고]` |
| 경사 | `[출산소식]` |

회사 경조사 메일은 이 말머리를 붙여 보낸다. 다른 경사 알림은 없다.

- 말머리를 제목 어디에서든 찾으므로 `FW: [부고] …`, `RE: [출산소식] …` 같은 전달·회신 메일도 빠진다.
  `[부고]` `[출산소식]` 은 대괄호까지 포함해 찾으므로 `부고` 라는 단어만 들어간 회사 공지는 빠지지 않는다.
  `訃告` 는 한자라 회사 공지에 쓰일 일이 없어 괄호 없이 찾는다. `[訃告]`, `(訃告)`, `訃告 -` 모두 빠진다
- **말머리 추가:** 식 맨 끝 `))))` 바로 앞에 `, contains(coalesce(item()?['subject'], ''), '[새말머리]')` 를 끼워 넣는다
- **말머리 빼기:** 해당 `contains(...)` 하나와 그 앞의 `, ` 를 지운다

## 10. `SelectMail` — 메일을 카드 줄로 변환

액션 추가 검색에 `선택` → **데이터 작업** 의 **선택(Select)** → 이름 `SelectMail`.

- **From** 칸 → **[식]** `body('FilterMail')`
- **Map** 칸 옆의 **텍스트 모드로 전환(Switch Map to text mode)** 아이콘을 누르면 키/값 두 칸이 텍스트 칸 하나로 바뀐다.
  그 칸에 아래를 **[붙여넣기]**

```json
{
  "type": "TextBlock",
  "text": "• @{item()?['subject']}  ·  @{item()?['from']}",
  "wrap": true,
  "spacing": "None"
}
```

## 11. `MailItems` — 메일이 없을 때 대체 문구

**작성** 액션 추가 → 이름 `MailItems` → 입력에 **[식]**:

```
if(empty(body('FilterMail')), json('[{"type":"TextBlock","text":"특이사항 없음","isSubtle":true,"spacing":"None"}]'), body('SelectMail'))
```

## 12. 카드 게시

액션 추가 검색에 `Post card` → **Microsoft Teams** 의 **채팅 또는 채널에 카드 게시 (Post card in a chat or channel)**.
이름은 바꾸지 않아도 된다 (다른 식이 참조하지 않는다).

| 매개 변수 | 값 |
|---|---|
| 게시자 | 목록에서 `Flow bot` |
| 게시 위치 | 목록에서 `Channel` (테스트 중에는 `Chat with Flow bot`, 13절) |
| 팀 / 채널 | 목록에서 브리핑을 받을 팀과 채널 |
| Adaptive Card | 아래 JSON 을 **[붙여넣기]** |

```json
{
  "type": "AdaptiveCard",
  "$schema": "http://adaptivecards.io/schemas/adaptive-card.json",
  "version": "1.4",
  "body": [
    { "type": "TextBlock", "text": "@{outputs('Title')}", "weight": "Bolder", "size": "Medium", "wrap": true },
    { "type": "TextBlock", "text": "✅ 팀 업무", "weight": "Bolder", "spacing": "Medium" },
    { "type": "TextBlock", "text": "• @{outputs('Rule')?['task']}", "wrap": true, "spacing": "Small" },
    { "type": "TextBlock", "text": "📅 전사 이슈 리마인드", "weight": "Bolder", "spacing": "Medium" },
    { "type": "Container", "spacing": "Small", "items": @{coalesce(outputs('MailItems'), json('[]'))} }
  ],
  "actions": @{coalesce(outputs('Rule')?['actions'], json('[]'))}
}
```

`"items"` 와 `"actions"` 뒤의 `@{coalesce(...)}` 는 따옴표 없이 넣는다. 배열이 JSON 으로 그대로 들어간다.
`coalesce(..., json('[]'))` 는 값이 비어 있으면 빈 배열 `[]` 을 대신 넣는다. 이게 없으면 `"actions": ,` 처럼 값이 빠진 JSON 이 되어
`InvalidBotRequestMessageBody` 오류가 난다 (13절).
붙여 넣은 `@{...}` 는 저장 후 토큰 모양으로 보일 수 있다. 정상이다.

### 완성된 흐름 모양

```
Recurrence
  → Now → Holidays → 조건 ─ True: 종료
                         └ False: (비움)
  → DayRules → Rule → Title → Since
  → GetMail → FilterMail → SelectMail → MailItems
  → 채널에 카드 게시
```

## 13. 테스트

1. 12단계 게시 위치를 `Chat with Flow bot`, 받는 사람을 본인으로 둔다
2. 5단계 `Rule` 식에서 `string(dayOfWeek(outputs('Now')))` 를 `'1'` 로 바꾸고 **테스트 → 수동** 으로 실행한다.
   `'2'` ~ `'5'` 까지 바꿔 가며 다섯 장을 모두 확인한다
3. 확인이 끝나면 `Rule` 식을 원래대로 되돌리고, 게시 위치를 팀 채널로 바꾼다
4. **기존 월요일 TimeSheet / 금요일 주간보고 알림 흐름을 끈다** (삭제 말고 끄기. 문제가 생기면 다시 켠다)

### 카드 게시에서 `InvalidBotRequestMessageBody` (유효하지 않은 JSON) 가 나면

`@{...}` 를 채운 결과가 JSON 이 아니라는 뜻이다. 실제로 만들어진 본문을 보고 깨진 곳을 찾는다.

1. 실패한 실행을 연다 → 빨간 **채팅 또는 채널에서 카드 게시** 카드를 누른다
2. 패널의 **입력 표시**(또는 **원시 입력 표시**)에서 카드 본문 문자열을 본다
3. 흔한 원인

   | 본문에서 보이는 것 | 원인 | 고치기 |
   |---|---|---|
   | `"actions": }` 또는 `"items": }` | 값이 비어 있다. `DayRules` 에서 그 요일의 `actions` 키가 빠졌거나, 이전 버전(`button`/`url`)의 `DayRules` 를 쓰고 있다 | 4단계 `DayRules` 를 최신 내용으로 다시 붙여 넣고, 12단계 카드를 `coalesce` 버전으로 바꾼다 |
   | `"text": "• ...따옴표"..."` | `task` 문구에 큰따옴표 `"` 가 있다 | `DayRules` 의 `task` 에서 `"` 를 `'` 나 `「」` 로 바꾼다 |
   | `"items": "[{...}]"` (배열이 따옴표로 감싸짐) | 카드 JSON 에서 `@{...}` 를 따옴표 안에 넣었다 | `"items"` / `"actions"` 뒤의 따옴표를 지운다 |

4. 같은 패널에서 앞 단계 `Rule` 과 `MailItems` 의 **출력** 도 확인한다. `Rule` 출력에 `actions` 가 있어야 한다

## 14. 운영 메모

- **흐름은 만든 사람의 Outlook 권한으로 돈다.** 퇴사·계정 변경 시 멈춘다.
  흐름 세부 정보 → **소유자** 에 팀원 한 명을 공동 소유자로 추가해 둔다.
  공동 소유자는 흐름을 고칠 수 있지만, 메일 조회 연결은 여전히 만든 사람 계정이다.
- **카드에 메일 원문 링크를 넣지 않는다.** 메일 ID 는 흐름 소유자 메일함 기준이라
  다른 팀원이 누르면 열리지 않는다. alias 메일은 팀원 모두의 받은편지함에 같이 있으므로
  제목으로 찾으면 된다.
- 개인 메일이 섞이지 않는 근거는 8단계의 `To Or CC` 필터 하나다. alias 주소를 넓게 잡지 않는다.
- 알려진 한계
  - 공휴일 다음 날은 조회 구간이 24시간이라, 휴일 전날 08:30 ~ 휴일 08:30 사이 메일이 빠진다.
  - 금요일이 공휴일이면 목요일 문구("금요일 휴가자는…")가 맞지 않고 금요일 주간보고 알림도 나가지 않는다.
  - alias 가 BCC 로만 들어온 메일은 `To Or CC` 에 걸리지 않는다.
  - `To Or CC` 필터는 폴더의 최근 메일 250통 안에서만 적용된다 (커넥터 문서). 3일 사이 받은편지함에 250통 넘게 쌓이면 오래된 alias 메일이 빠질 수 있다.
